# Groove Sprout

A effect VST3 plugin generated by PromptPlug.

## Get the .vst3 file (no coding needed)
1. Create a free account at github.com and click **New repository** (any name).
2. Click **uploading an existing file**, drag in everything from this unzipped folder
   (including the hidden `.github` folder — on Mac press Cmd+Shift+. to show it), then **Commit**.
3. Open the **Actions** tab. A build starts automatically (~10 minutes).
4. When it shows a green tick, open it and download **GrooveSprout-VST3-Windows** or **GrooveSprout-VST3-macOS**.
5. Unzip and copy `GrooveSprout.vst3` into your plugin folder:
   - Windows: `C:\Program Files\Common Files\VST3`
   - macOS: `~/Library/Audio/Plug-Ins/VST3` (if blocked, run `xattr -cr ~/Library/Audio/Plug-Ins/VST3/GrooveSprout.vst3`)
6. Rescan plugins in your DAW.

## Build locally
```
cmake -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build --config Release
```
